cliente -- pedido --> API -- resposta --> cliente

GET -- busca
POST -- criar 
PUT -- susbtitui
PATCH -- altera 
DELETE -- remove

-- STATUS CODES COMUNS --

200 - OK - DEU CERTO, AQUI TA OS DADOS

201 - OK - POST DEU CERTO, CRIOU O QUE VOCE ENVIOU

401 - NAO OK - NAO AUTENTICADO, FALTOU A CHAVE/TOKEN OU O TOKEN ESTÁ ERRADO.

404 - NÃO OK - NÃO ENCONTRADO, O ENDEREÇO OU O ID QUE VOCE REQUISITOU NÃO EXISTE

405 - NÃO OK - MÉTODO NÃO PERMITIDO, O ENDEREÇO EXISTE, MAS NÃO ACEITA O MÉTODO QUE VOCE UTILIZOU.

422 - DADOS INVÁLIDOS - O CORPO OU O PARAMETRO QUE VOCE UTILIZOU NÃO SEGUE O COMBINADO DA API.

500 - ERRO INTERNO - NAO TEM O QUE FAZER, FUDEU, SERVIDOR CAIU

1. Qual é o status? Qual o número que vem primeiro? (2, 4 ou 5?)
    - 401 = olhar primeiro autenticação
    
    - 404 = olhar primeiro no path
        exemplo:
        GET /filme/2                       # deveria ser GET/filmes/2
        -> 404 {"detail": "Not Found"}
    
    - 405 = olhar primeiro o metodo
        exemplo:
            POST /filmes/2
            -> 405 {"detail": "Method Not Allowed"}
    
    - 422 = olhar no corpo, olhar os parametros
        exemplo:
            POST /filmes
            {
                "titulo": "A Névoa do Pântano", 
                "genero": "zumbi", 
                "ano": 2026, 
                "nota": 12
            }
            → 422  {"detail": "nota deve estar entre 0 e 10"}
    
    - 500 = AJOELHA E REZA PAE
    
    - 200 enganoso (filtros que aplicamos) 
        - não tem dados para retornar
            exemplo: 
            [{
                "nome": "",
                "idade": "",
            }]
            exemplo 2:
            GET /filmes?genero=zumbis
            -> 200 []
